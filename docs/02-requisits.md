# Requisits

## Rols

L’aplicació tindrà els rols següents:

- **Policia**
- **Usuari normal**

## Permisos

### Policia

La policia podrà:

- Certificar avisos.
- Fer que determinats avisos siguin més destacats.
- Modificar el llistat de les persones més perilloses d’Espanya.
- Fer tot el que pot fer un usuari normal.

### Usuari normal

Un usuari normal podrà:

- Fer avisos sobre delictes que li hagin passat.
- Veure al mapa els avisos dels altres usuaris.
- Consultar quines són les persones més perilloses d’Espanya.
